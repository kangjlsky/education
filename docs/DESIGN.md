# 柠柠学习工作台 · 详细设计文档

> 项目名：柠　工作台名：柠柠学习工作台
> 适配：4 岁男童，每周 ≥5 天打卡
> 版本：v0.1（设计稿）

---

## 1. 项目概述

### 1.1 定位

面向 4 岁学龄前儿童的习惯养成 + 启蒙学习工具，跑在家长手机上，**孩子自己操作**（大按钮、图标主导、语音引导），**家长在后台做最终确认**（发放勋章奖励、调整任务量）。

### 1.2 核心原则

| 原则 | 说明 |
|---|---|
| 孩子可独立操作 | 全屏大按钮、图标 + emoji 主导、几乎无文字依赖、语音朗读引导 |
| 家长有控制权 | 家长后台密码进入；勋章"兑换成实际奖励"必须家长确认 |
| 数据不丢失 | 全部本地持久化（localStorage），关闭页面不丢 |
| 可添加到主屏 | PWA：全屏运行、有图标、离线可用 |

### 1.3 与原"宝宝启蒙工作台"的关系

全新独立项目，放在 `ning-workbench/` 目录，**不影响原项目文件**。内容数据结构（古诗、字、单词）可借鉴原项目已有的数据结构，内容量按本规格扩充。

---

## 2. 技术选型

| 项 | 选型 | 理由 |
|---|---|---|
| 形态 | PWA（纯前端） | 零后端零成本，手机浏览器打开即用，可"添加到主屏"全屏运行 |
| 存储 | localStorage | 单用户、数据量小（<1MB），JSON 直接存取，简单可靠 |
| 语音 | Web Speech API | 中文/英文朗读，浏览器内置，无需额外资源 |
| 描红 | Canvas 2D | 笔迹绘制 + 笔画覆盖判定 |
| 动画 | CSS transitions + 少量 JS | 按钮缩放、飘星星、宠物动作 |

**不做**：账号系统、云同步、后端服务（后续需要再加，不影响当前设计）。

## 3. 双模式与信息架构

应用分两个模式，入口互不相通（儿童模式无密码入口，家长模式有密码）：

```
柠柠学习工作台
├── 儿童模式（默认进入）
│   ├── 首页：6 大板块卡片 + 宠物 + 今日进度环
│   ├── 国学 ── 本周古诗学习 → 古诗列表 → 古文
│   ├── 识字 ── 今日 2 新字 → 滚动复习 → 认字小测
│   ├── 数学 ── 6 阶段 → 每日 2-3 个小游戏
│   ├── 英语 ── 单词卡 → 绘本跟读
│   ├── 控笔 ── 每日描红 2-3 个
│   ├── 我的宠物 ── 宠物互动
│   └── 勋章屋 ── 勋章进度与收集
└── 家长模式（密码进入）
    ├── 数据看板（打卡日历 / 各科进度 / 宠物成长 / 勋章记录）
    ├── 自定义设置（任务量 / 兑换规则 / 孩子信息）
    ├── 每日学习报告
    └── 勋章兑换确认
```

顶部常驻：星光数、宠物头像（可点击）、今日打卡状态。

## 4. 儿童端页面设计

### 4.1 首页

- 顶部问候语："柠柠，今天想玩什么呀？"（语音朗读）
- **6 个大卡片**（2 行 × 3 列）：国学 📖 / 识字 ✏️ / 数学 🔢 / 英语 🔠 / 控笔 🖍️ / 勋章 🏆，每个卡片 = emoji + 名称 + 一句引导语，卡片高度 ≥ 屏幕 1/4，圆角大按钮
- 底部横条：今日进度（已打卡 N/计划 M）+ 宠物（点击进入宠物页）
- 每日首次进入自动语音："早上好柠柠，今天也要加油哦！"

### 4.2 国学板块

- **本周古诗区**：本周 3 首（家长可调数量），每首卡片：诗名 + 作者 + emoji + "开始学"大按钮
- **学习页**：逐句大图大字 + 点句朗读（中文语音）→ 跟读（可选录音，4 岁不强求）→ "我会背啦！"打卡按钮
- **古诗列表**：全部已学/未学状态，已学打 🌸，未学 🔒（或灰色）
- **古文区**：每学满 10 首古诗解锁 1 篇古文（国学馆徽章）
- **复习机制**：每周日自动进入复习模式——本周 3 首 + 随机抽 2 首旧诗，背完即完成
- 数据结构：`{ id, name, author, ico, text: [行], trans: [白话], stage }`

### 4.3 识字板块

- **今日学习**：2 个新字（大字 + 实物 emoji + 拼音 + 一句短语），点字朗读
- **滚动复习**：之前学过的字以卡片流出现，认出一个划掉一个（间隔复习：按学习天数排序，优先复习 1/3/7 天前学的字）
- **认字小测**：4 选 1（看图选字 / 看字选图），答对飘星星
- 每周 10 个新字 = 周一至周五每日 2 个
- 数据结构：`{ char, pic, py, phrase, group }`，进度存 `learned: [id 数组] + learnDate`

### 4.4 数学板块

6 阶段循序渐进，完成当前阶段全部小游戏解锁下一阶段（家长可在后台跳过/解锁）：

| 阶段 | 内容 | 小游戏示例（每日 2-3 个） |
|---|---|---|
| 1 数感 | 1-20 数数、数量对应 | 数一数（点物品数数量）、数字大冒险 |
| 2 排序 | 大小、长短、高矮比较 | 比大小、排队啦 |
| 3 图形 | 基础形状认知 | 找形状、拼图形 |
| 4 20 以内加减 | 10 以内 → 20 以内 | 算一算（选择大按钮）、凑十游戏 |
| 5 钟表 | 整点、半点 | 认时钟（指针转盘） |
| 6 钱币 | 认识元角分、简单购物 | 小超市（付钱买东西） |

- 每个小游戏：进入 → 语音念题 → 大按钮选择 → 答对飘星星 + 音效，答错温柔提示重试
- 数据结构：`{ stage, games: [...] }`，进度存 `{ stage, doneGames: [], correctCount }`

### 4.5 英语板块

- **单词卡**：本周新词（每周新词数家长可调），点卡片看 emoji + 听发音（英文语音）
- **绘本跟读（RAZ AA）**：每周 3 本（可调），每本 5-8 页：一页一句 → 点句子朗读 → 孩子跟读（录音可选）→ 翻页
- **定期复盘**：每周六自动复盘本周单词 + 3 本绘本
- 数据结构：单词 `{ word, cn, ico, py, theme }`；绘本 `{ id, title, pages: [{ en, cn, ico }] }`

### 4.6 控笔板块（描红）

- **每日任务**：2-3 个描红字（家长可调），内容：数字（1-10）→ 简单偏旁 → 简单汉字（人、口、手、山…）分级
- **描红交互**：Canvas 显示浅灰虚线底字，孩子用手指沿笔画描，描过的部分变实心高亮色，覆盖到 80% 判定完成 → 飘星星 + 语音"写得真棒！"
- 不追求笔顺正确（4 岁），只求描完、有趣
- 数据结构：`{ id, char, strokes: [笔画路径点集] }`

### 4.7 我的宠物

- 一只宠物（默认小恐龙 🦖，家长可换主题：小猫/小狗/小恐龙）
- **打卡自动喂食**：每次完成任意打卡 → 宠物吃食物动画（+1 口粮，纯趣味不计数）
- **点按互动**：点宠物头部 = 摸头（冒爱心），点食物盘 = 喂食动画
- **成长**：宠物等级 = 累计星光数，每 10 星光升 1 级，升级时体型长大 / 换装饰 + 庆祝动画
- **今日状态**：今天喂过几次、等级、距离升级还差几颗星（对 4 岁展示为进度条 + 语音）

### 4.8 勋章屋

- 显示已获勋章数 + 下一枚进度（还差 N 颗星光）
- 每集齐 5 星光 → 自动获得 1 枚勋章 → **全屏庆祝动画**（飘星星 + 烟花 + 语音"恭喜柠柠获得勋章！"）
- 勋章展示：当前勋章数 + 历史记录（日期 + 来源）

## 5. 积分与激励系统（简化版）

> 相对原规格简化：取消"宠物粮"独立计数、取消"宝石"、取消 0.5 小数、取消分板块差异。只保留一种货币 **星光**，勋章由星光自动换算。

### 5.1 积分规则

| 事件 | 奖励 |
|---|---|
| 任意板块完成一次打卡 | +1 星光，宠物自动喂食 1 次 |
| 每周打卡 ≥5 天 | +3 星光（周末结算） |
| 每集齐 5 星光 | 自动获得 1 枚勋章（庆祝动画） |

### 5.2 勋章兑换（家长后台可修改数值）

| 勋章数 | 奖励 |
|---|---|
| 2 | 零食一次 |
| 3 | 动画片 1 集 |
| 5 | 5 元零花钱 |

**兑换流程（家长最终确认）**：孩子攒够勋章 → 向家长提出 → 家长在后台点"兑换 + 发放" → 记录扣减勋章、生成兑换记录。**只有家长确认发放，勋章才真正扣减**——孩子看到的是"等家长确认"状态。

### 5.3 节奏验证

每周全勤 5 天 = 5 星光 + 3 = 8 星光 ≈ 1.6 勋章/周。
- 零食：约 1 周多
- 动画片：约 2 周
- 零花钱：约 3 周

对 4 岁孩子：奖励感既不过密（避免无感）也不过远（避免失去兴趣）。

## 6. 家长后台设计

### 6.1 入口与安全

- 儿童模式**无任何入口**；家长模式入口：首页底部小字"家长"图标 → 4 位数字密码（默认 `0000`，首次进入强制修改）
- 密码错误 3 次锁定 30 秒

### 6.2 数据看板

| 模块 | 内容 |
|---|---|
| 打卡日历 | 月视图，打卡天打勾 ✅，全勤周高亮 |
| 各科进度 | 每科：已学/总量、本周完成数、最近 7 天打卡柱状图 |
| 宠物成长 | 等级、累计星光、升级历史 |
| 勋章记录 | 勋章获得/兑换历史列表 |

### 6.3 自定义设置

- 任务量：每周古诗数（默认 3）、每周生字数（默认 10）、每日新字（默认 2）、每周绘本数（默认 3）、每日描红数（默认 2-3）、每日数学游戏数（默认 2-3）
- 兑换规则：勋章兑换档位数值（默认 2/3/5）及对应奖励文案
- 孩子信息：昵称（默认"柠柠"）、宠物主题（恐龙/猫/狗）
- 家长密码修改
- 数据导出/重置（JSON 导出备份、一键清空重置）

### 6.4 每日学习报告

每晚生成（家长打开后台时展示）：今日打卡科目、完成情况、获得星光、勋章变化、一句话总结（如"今天柠柠把 3 首古诗都背完啦，太棒了！"）+ 明日计划预告。

## 8. 内容数据规划

内容库以 JS 常量文件存放（不进 localStorage）：

| 文件 | 内容 | 规模 |
|---|---|---|
| `js/data/poems.js` | 小学必背古诗 + 经典古文，含白话译文 | 169 首 + 古文 ≥16 篇（每 10 首解锁 1 篇） |
| `js/data/words.js` | 幼升小高频字，按 10 字/组分组 | 2000 字 / 200 组 |
| `js/data/math.js` | 6 阶段关卡与小游戏配置 | 每阶段 2-3 个游戏 × 6 |
| `js/data/english.js` | 学前单词（按主题分组）+ RAZ AA 绘本 | 500 词 + RAZ AA 全套（约 87 本） |
| `js/data/pen.js` | 数字/偏旁/汉字描红笔画数据 | 分级 ≥60 个 |

> 首批实现可先内置小样本（如古诗 30 首、字 200 个、单词 60 个、绘本 6 本）跑通流程，再逐步扩充到目标量——数据结构不变，只加数据。

## 10. 周计划与复习算法

- **周计划**：每周一自动生成——古诗 3 首、生字 10 个（周一至周五每日 2 新）、绘本 3 本
- **复习**：
  - 古诗：每周日复习本周 3 首 + 随机抽 2 首旧诗
  - 生字：每日穿插复习 1/3/7 天前学过的字（简单间隔重复，最多 6 个）
  - 英语：每周六复盘本周单词 + 绘本
- **全勤结算**：周日检查本周打卡 ≥5 天 → +3 星光 + 全勤庆祝动画

### 11.2 分阶段开发

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| **P1 骨架** | 目录结构、index.html、配色样式、导航、双模式框架、星光积分、localStorage 层 | 首页 6 卡片可点、打卡 +1 星光、刷新不丢 |
