# 09 — 宠物系统

**What to build:** 一只宠物（默认小恐龙）在每次打卡时自动播放进食动画；点击宠物可摸头（冒爱心）与喂食；等级 = 累计星光 / 10 向下取整，升级时体型长大动画 + 庆祝；宠物页展示今日喂食次数、等级与距下一级进度。

**Blocked by:** 02 — 星光打卡闭环

**Status:** ready-for-agent

- [ ] 任意板块打卡触发宠物进食动画
- [ ] 点按互动（摸头 / 喂食）有对应反馈
- [ ] 星光达到 10 的倍数时宠物升级并展示成长变化
- [ ] 等级计算为纯函数，有自动化测试
- [ ] 宠物数据持久化，重开不丢
